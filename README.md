
# Danny G. explorations in Visual Arts using p5.js

Welcome to my collection of interactive visual art projects, all built using **p5.js**, a JavaScript library that simplifies creative coding. This repository showcases a variety of personal experiments and artistic expressions, each designed to explore the boundaries of digital art through programming.

## Explore the Projects

You can view and interact with these sketches live on my interactive web page. Each project is designed to allow users to engage directly with the artwork, providing a more immersive experience.

[**Explore the interactive sketches here**](https://degarzonm.github.io/p5sketches/)

## About the Projects

This page contains several sketches that represent different aspects of my exploration with **p5.js**, including generative art, algorithmic design, and interactive visualizations. Some projects involve real-time user interaction, while others demonstrate the dynamic and evolving nature of code-based art.

Each sketch is an opportunity to see the fusion of creativity and code in action, and you are encouraged to experiment and discover new aspects of each one as you interact with them. The live page allows you to:

- **Engage**: Click, drag, and manipulate elements of the sketch.
- **Observe**: Watch as the art evolves and changes with time or user input.
- **Explore**: Dive into the code (available here on GitHub) and see how the artwork is generated.

## Features

- **Interactive Art**: The sketches are designed to respond to user input, such as mouse movements, clicks, or key presses, creating a dynamic experience.
- **Generative Design**: Many of the projects generate patterns, animations, and visual effects algorithmically, offering endless variations.
- **Live View**: The interactive page hosts all the sketches, allowing for real-time exploration and experimentation with each one.

## Getting Started

To run the sketches locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/degarzonm/p5sketches.git
   ```

2. Navigate to the project directory:
   ```bash
   cd p5sketches
   ```

3. Open the `index.html` file in your web browser to view the sketches locally.
